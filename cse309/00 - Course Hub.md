# CSE 309 — Compiler

> 3 hours/week · 3 credits

## Course Description

Compiler structure, lexical analysis, syntax analysis, syntax-directed translation,
intermediate-code generation, runtime environments, code generation,
machine-independent optimization, and interprocedural analysis.
