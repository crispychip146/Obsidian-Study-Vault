# CSE 313 — Operating System

> 3 hours/week · 3 credits

## Course Description

Operating system concepts, process management, CPU scheduling,
process synchronization, deadlocks, memory management, I/O,
file systems, protection, and multiprocessor systems.

---

- Role of Operating Systems

- Multiuser Operating Systems
