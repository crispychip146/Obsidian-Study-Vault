# CSE 315 — Microprocessors, Microcontrollers, and Embedded Systems

> 3 hours/week · 3 credits

## Course Description

Microprocessors and microcontrollers, computer architecture,
instruction sets, memory architecture, I/O, peripherals, interrupts,
timers, buses, interfacing, communication, sensors, actuators,
embedded systems, IoT, and real-time operating systems.
